# assets/input.wav — Not Included in This Sample

This app reads `assets/input.wav` (mono, 16-bit PCM, 16000 Hz) as its ASR input.

No audio file is committed to this repository. This sample does not bundle any input or output WAV file, by design.

To run this sample, supply your own short WAV recording matching the format above and place it at `assets/input.wav`. See the main [README.md](../README.md#4-setup) for the full Setup instructions, including how to change the input path or use a microphone/speaker instead of files.
